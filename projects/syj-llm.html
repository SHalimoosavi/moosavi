SYJ-LLM

Offline-first LLM runtime and local AI infrastructure. Offline-first, low-RAM LLM runtime with a local GGUF model registry, memory-aware admission, CLI workflows, localhost API and fine-tuning pipeline.

Current phase: Phase 5 — Fine-Tuning PipelineC++17 · llama.cpp · GGUF · CMake · ARM64
Open source repository ↗

Why it matters

SYJ-LLM is the flagship systems project. Its architecture keeps the inference core native, separates the optional HTTP layer, pins llama.cpp, classifies model memory requirements and supports constrained ARM64/Termux environments.

Architecture lens

SYJ-LLM │ ├── CORE / DOMAIN LOGIC ├── DATA / MODEL LAYER ├── API / CLI SURFACE ├── TESTING / VALIDATION └── DOCUMENTATION / RELEASE Design principle: keep the core understandable, testable and portable.
